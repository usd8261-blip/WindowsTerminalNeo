# Windows Terminal Neo — Десктопное приложение для Windows

В архиве подготовлены все компоненты для запуска и сборки в автономный `.exe`:

### Вариант 1. Мгновенный запуск без установки компиляторов
Просто дважды кликните на **`run_app.bat`**. 
Он запускает терминал в нативном отдельном окне Windows без адресной строки и вкладок браузера (через встроенный в Windows движок Edge App Mode).

### Вариант 2. Компиляция в единый автономный `WindowsTerminalNeo.exe`
1. Дважды кликните на **`build_exe.bat`**.
2. Скрипт автоматически упакует всё в единый `.exe` файл с помощью PyInstaller.
3. Готовый файл появится в папке `dist\WindowsTerminalNeo.exe`.

### Вариант 3. Сборка через Electron
1. `npm install electron`
2. `npm run build:exe`
