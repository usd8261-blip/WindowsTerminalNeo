Локальная нейросеть: Ollama + Qwen 2.5 Coder Для новичков
Простой туториал и установка полноценной языковой модели на ваш ПК
💡 Что это такое простыми словами?

Вы можете запускать настоящую большую нейросеть прямо на своем компьютере, как программу. Она работает без интернета, моментально отвечает на любые вопросы по коду, скриптам и Windows, а ваши данные никогда не покидают ваш ПК.

1 Шаг 1: Скачайте движок Ollama
Статус: Не проверено

Ollama — это бесплатный официальный сервис для Windows, который загружает и запускает нейросети в видеопамять (VRAM).

Скачать инсталлятор (.exe)
Официальный сайт ollama.com
Либо введите в терминал:
winget install Ollama.Ollama
После установки Ollama запустится в трее Windows (возле часов).
2 Шаг 2: Скачайте модель Qwen 2.5 Coder

Qwen 2.5 Coder от Alibaba — одна из самых мощных моделей в мире для кода. Она оптимизирована под скрипты, знает русский язык и отлично ориентируется в командах Windows.

Qwen 2.5 Coder (1.5B) Оптимально (~950 MB)
Команда для скачивания в терминале:
ollama run qwen2.5-coder:1.5b
Qwen 2.5 Coder (0.5B Ultra-light): всего 390 MB для слабых видеокарт
ollama run qwen2.5-coder:0.5b
